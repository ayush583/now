# Sonii's Birthday Website

1. `npm install`
2. `npm run dev`  (open the network URL on your phone to preview)
3. Edit `src/data.js` for all text, captions, her likes, the moon message and the letter
4. `npm run build`, then upload the `dist/` folder to Netlify or Vercel to get a link

Note: the "blow with your mic" feature needs https (Netlify/Vercel give you that).
On plain http it falls back to tapping the candles, which always works.
